📋 1. 项目总览

R1 是一款面向 RoboMaster 竞赛的实时嵌入式机器人控制系统。项目基于 STM32H723 Cortex-M7 微控制器，搭载 FreeRTOS 实时操作系统，集成了 CAN 总线通信、IMU 惯性导航、遥控器接收、多轴电机控制、底盘运动学解算、机械臂/武器系统管理等功能模块，构成完整的机器人运动与控制闭环。

目标平台

STM32H723VGT6, ARM Cortex-M7 内核, 最高主频 480MHz, Flash 1MB, SRAM 564KB, LDO 供电模式

H723Cortex-M7480MHz

操作系统

FreeRTOS 10.x 配 CMSIS-RTOS V2 接口层，3 个用户任务 (defaultTask / FreeTask / SentTask)，heap_4 内存管理

FreeRTOSCMSIS-RTOS2heap_4

开发环境

Keil MDK-ARM IDE 编译，STM32CubeMX 生成 HAL 外设驱动框架，用户应用逻辑位于 user/ 目录，三层代码结构

Keil MDKCubeMXHAL

版本说明

R1 为基础版本，HI14 IMU 通过 USART2 RS485 外接。RC26_H7_R2 为升级版，整合 BMI088 IMU SPI 直驱、USB PCD 及更多应用模块

⏱️ 6. 运行时任务与中断架构

ISR 层 —— 硬实时中断驱动

定时器驱动的三级中断架构：

  • TIM12 (5kHz) → IMU 数据帧解析与请求
    IMU_ParseFrameIfReady() + IMU_RequestAndStartRx()
  • TIM5 (2.5kHz) → HF_Task() CAN 高频发送
  • TIM4 (10kHz) → LF_Task() 低频控制逻辑
    底盘解算、PID 更新、状态机
  • UART5 IDLE → REMOTE_IdleHandler() 遥控帧处理
硬实时中断驱动

RTOS 层 —— 并发任务

FreeRTOS 三任务，CMSIS-RTOS V2 API：

defaultTaskNormal128x4B空闲/监控
FreeTaskAboveNormal128x4B__weak 可重载
SentTaskRealtime128x4B__weak 可重载
FreeRTOS3 Tasks

📦 7. 核心模块功能详解

🔵 通信子系统

remote_control

DBUS 遥控器协议解析。UART5 DMA 循环接收 + IDLE 中断检测帧边界，解析 18 字节 DBUS 帧，映射为控制指令。

DBUSUART5IDLE

Can_Task + bsp_can

CAN 总线管理层。bsp_can 负责 3 路 FDCAN 滤波器和收发；Can_Task 将控制指令打包发送给电机/执行器。

FDCANx3滤波HF_Task

bsp_uart

串口板级支持包。管理 4 路 UART DMA 收发缓冲区，支持 RS485 方向控制 (USART2_DE)，提供统一回调接口。

UARTx4DMARS485

🟢 运动控制子系统

chassis

麦克纳姆轮全向底盘运动学解算。vx/vy/vw → 四轮独立转速，实现全向运动。

麦克纳姆轮全向

motor / motor_control

电机抽象层 + PID 控制算法。motor 封装协议细节，motor_control 实现速度/位置/力矩闭环。

PID闭环

dji_motor / dm_motor

DJI M3508/M2006/GM6020 和 DM 系列电机 CAN 协议实现，指令编码与反馈解析。

M3508M2006GM6020

pid

通用 PID：P/PI/PD/PID，积分分离、输出限幅、死区控制、微分先行等工程优化。

PID积分分离

Motion_Task

运动规划与轨迹生成，协调底盘/云台多轴联动，输出目标值给底层控制环。

轨迹联动

🟠 执行机构子系统

weapon

武器系统：拨弹/摩擦轮控制、弹量检测、发射节奏、安全互锁。

发射拨弹

arm + lift + kfs

多自由度机械臂/升降/KFS 机构独立控制，运动学逆解、限位、PID 伺服。

机械臂升降

cowork

多机构协同：抓取-举升-放置等战术动作序列的协调配合。

协同序列

🟣 传感器与决策

imu (HI14)

HI14 IMU 通过 USART2 RS485 通信，TIM12 以 5kHz 触发解析，获取角速度/加速度/欧拉角。

HI145kHz

master_control + policy

系统主状态机 (待机/遥控/自动) + 战术决策 (进攻/防守/辅助)。

状态机战术

auto_mode

自动模式：基于 IMU 的自主导航、预设路径跟踪、自动瞄准。

导航瞄准

🩷 系统支撑

register / structure

Structue_Init() 统一注册入口，初始化数据结构，建立模块间引用关系。

初始化

global / timer

跨模块全局状态变量 + LF_Task/HF_Task 两级定时处理 (TIM4/TIM5 ISR)。

全局LF/HF

bsp_tim

定时器 BSP，统一管理 TIM 中断回调注册，为业务模块提供周期触发服务。

回调

💡 11. 关键设计模式

🔴 ISR + RTOS 混合架构

硬实时控制 (CAN发送/IMU采集) 放在 ISR 定时器精确驱动；非实时任务在 FreeRTOS 调度。

🟠 电机分层抽象

motor(接口) → dji_motor/dm_motor(协议) → CAN(传输)。更换电机只需换底层。

🟢 BSP 模式分离硬件

bsp_can/uart/tim 封装 HAL，业务模块不直接依赖 HAL，MCU 变更只改 BSP。

🔵 __weak 可重载任务

FreeTask/SentTask 声明 __weak，user/ 层重载不修改 Core/ 代码，保护 CubeMX 再生。

🟣 全局状态 + 模块组合

global 跨模块共享，各模块独立开发，通过 cowork + master_control 组合。

🩷 CubeMX 代码再生安全

USER CODE BEGIN/END 块保护用户代码，CubeMX 重新生成不丢失业务逻辑。
